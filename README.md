# 함께하는 시민행동 홈페이지 개편 시안 (검토용)

**실제 홈페이지가 아닙니다.** 함께하는 시민행동(action.or.kr) 홈페이지 개편안을
관계자가 화면으로 확인하기 위한 검토용 사본입니다.

- 실제 홈페이지: <https://action.or.kr>
- 이 저장소는 **자동으로 만들어진 결과물**입니다. 여기서 직접 고치지 마세요.
- 화면은 일곱 개뿐입니다. 소개·공지·발행물 같은 나머지 메뉴는 실제 홈페이지의
  게시판이라 여기엔 담겨 있지 않습니다(눌러도 안 열리는 게 정상입니다).
- 화면에 보이는 주황색 **'확인 필요'** 딱지는 아직 사람이 채워야 하는 값입니다.

검색엔진에는 잡히지 않도록 해 두었습니다(noindex).
